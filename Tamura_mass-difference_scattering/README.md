## Tamura mass-difference scattering

 In this mechanism, random mass substitution in the SiGe alloy scatters phonons at a rate

$$\[
\tau_{\mathrm{md}}^{-1}(\omega)\propto \omega^2D(\omega),
\]$$

resulting in a frequency-dependent mean free path,

$$\[
\Lambda(\omega)=v_g(\omega)\tau_{\mathrm{md}}(\omega).
\]$$

The scattering layer is then treated as a phonon radiative-transport problem—the phonon analogue of the radiative transfer equation—and solved using the discrete-ordinates package **PythonicDISORT** (D. J. X. Ho; `pip install PythonicDISORT`) to obtain the transmittance spectrum shown in Figs. 2, 3, 4, S6, S7, and S8.

The cumulative transmittance is the product of the AMM (angular) and
scattering (spectral & angular) contributions.

```bash
python -m venv venv && source venv/bin/activate

```

## Quick start

Regenerate every figure into `figures/`:

```bash
python generate_all_figures.py
```

or step through the annotated walkthrough:

```bash
jupyter notebook notebooks/reproduce_figures.ipynb
```

Programmatic use:

```python
import numpy as np
import phonon_filters as pf
from phonon_filters import dataio, scattering, transport, figures

# DFT density of states -> SiGe mean free path
nu_THz, _, dos = dataio.read_dos_average(dataio.default_dos_paths())
_, mfp = scattering.mass_difference_mfp_dft(nu_THz, dos)
nu_Hz, mfp_tr, _ = dataio.truncate_mfp(nu_THz * 1e12, mfp, dos)

# transmittance vs frequency for a few single-scattering albedos
sweep = transport.flux_albedo_sweep(mfp_tr, [0.001, 0.5, 0.99, 0.999999], L_um=1.0)
figures.figure4(nu_Hz / 1e9, sweep, [0.001, 0.5, 0.99, 0.999999])
```

## The layout of this part

```
phonon_filters/        importable package
  materials.py         acoustic property tables, alloy lists, elemental loader
  dataio.py            DOS file reading, element<->symbol maps, array truncation
  dispersion.py        Born--von Karman group velocity and density of states
  scattering.py        Tamura mass-difference lifetimes and mean free paths
  amm.py               acoustic-mismatch interface and multilayer transmission
  transport.py         DISORT radiative-transport sweeps
  thermal.py           Bose-Einstein occupation, DOS weighting, Debye integrand
  figures.py           one generator per manuscript figure
data/                  DFT DOS files (3 SiGe phases) + elemental properties JSON
notebooks/             reproduce_figures.ipynb (full walkthrough)
figures/               generated output
generate_all_figures.py  one-shot driver
```

## Inputs

The only primary inputs are the three DFT phonon density-of-states files in
`data/` (the cubic, hexagonal and monoclinic SiGe phases), which are read and averaged
onto a common grid. The elemental property table (`data/elemental_properties.json`)
supplies atomic masses, densities, sound velocities, and atoms per primitive
cell for the Born--von Karman dispersion. Everything else (mean free paths,
optical depths, transmittance grids) is computed.
